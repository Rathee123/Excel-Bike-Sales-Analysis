# Bike Sales Analysis | Excel Dashboard

## 📌 Project Overview

This project focuses on exploring customer demographics and bike purchasing behaviour using Microsoft Excel. The objective is to transform raw customer data into meaningful insights through data preparation, PivotTables, visualizations, and an interactive dashboard.

The dashboard enables users to explore purchasing patterns across different demographic groups and commute distances using interactive filters.

## 🎯 Business Objectives

* Analyse bike purchasing behaviour across customer demographics.
* Compare average income between customers who purchased bikes and those who did not.
* Explore purchasing patterns across different age groups.
* Investigate how commute distance relates to bike purchasing behaviour.
* Enable interactive exploration of customer segments using dashboard filters.

## 🛠️ Tools & Technologies

* **Microsoft Excel**
* PivotTables
* PivotCharts
* Excel slicers
* Data cleaning and preparation
* Data visualization

## 📊 Project Workflow

### 1. Data Preparation

Reviewed the dataset and prepared the customer data for analysis.

### 2. Data Analysis

Created PivotTables to summarize customer purchasing behaviour across demographic categories.

### 3. Data Visualization

Developed charts to compare:

* Average income by gender and bike purchase status.
* Bike purchases across age groups.
* Bike purchases by commute distance.

### 4. Interactive Dashboard

Combined the visualizations into an Excel dashboard with slicers for:

* Marital status
* Education
* Region

These filters allow users to explore different customer segments.
